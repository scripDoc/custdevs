# Гайд по записи кастдева

Какой источник лучше под Whisper large-v3, как правильно писать, как обрабатывать.

## Точность Whisper large-v3 на русском

Базовый ориентир для понимания, чего ожидать.

| Условие записи | Точность (грубая оценка) | Что в результате |
|---|---|---|
| Чистая запись монолога, тихая комната | 95–97% | Расшифровка почти готова, нужна минимальная вычитка |
| Диалог двух людей, тихая обстановка | 88–93% | Нужна вычитка имён, терминов, иногда переспрашивать |
| Диалог в шумной обстановке | 75–85% | Местами теряются куски, но смысл сохраняется |
| Запись с динамика iPhone (не близко) | 70–82% | Падает быстро при удалении от микрофона |

Это для именованных слов, общеупотребимых — лучше. Для редких слов, имён, англицизмов — Whisper иногда придумывает похоже звучащее. Решение — `initial_prompt` в `transcribe.py` уже содержит твою терминологию (Claude Code, кастдев, и т.д.), это поднимает точность на этих словах.

**Главное:** Whisper не делает diarization — то есть не отделяет «кто что сказал». В расшифровке будет один поток текста с таймкодами, без меток говорящих. Для кастдева это **ОК**, потому что ты помнишь контекст и Claude в разборе по контексту разберётся, где говорит клиент. Если очень нужно — можно добавить `pyannote.audio` отдельным шагом, но это +30 минут к каждому разбору и редко стоит того.

## Сравнение твоих источников записи

### Yandex Телемост — встроенная запись

Записи сохраняются на Яндекс Диск автоматически, в формате **WEBM**. Хорошее качество, потому что записывается напрямую с микрофонов участников, без потерь от воздушной передачи.

**Плюсы:**
- Чистый источник звука у каждого участника
- Не зависит от шумов в комнате
- Не надо ничего отдельно включать (если запись разрешена)

**Минусы:**
- Запись доступна не всем тарифам — на бесплатном Телемосте записи не сохраняются автоматически. Нужен Яндекс 360
- Формат WEBM нужно конвертить в WAV/M4A для удобной работы (Whisper понимает WEBM, но утилитарно проще другой формат)
- Файл скачивается по ссылке только организатором встречи
- AI-конспекты от самого Яндекса — только корпоративные тарифы

### iPhone Voice Memos (диктофон)

Диктофон iPhone пишет в формате **M4A AAC**, 24-bit, 48kHz. Качество хорошее.

**Плюсы:**
- Универсально — работает для любых разговоров: онлайн, очно, по телефону, на улице
- Один файл, не надо конвертить
- Whisper понимает M4A напрямую, без ffmpeg-конвертации
- Бэкап есть всегда — даже если основной источник провалился

**Минусы:**
- Если разговор онлайн — пишется через громкую связь, качество удалённого собеседника ниже
- Один поток, нет разделения по говорящим (но Whisper их и так не разделит)
- В шумной комнате качество страдает

### Скринкаст десктопа (OBS / Karet)

Если оба собеседника онлайн (Telegram, Zoom, Meet), можно через **OBS Studio** записать звук системы целиком. Чистый источник звука обеих сторон.

## Какой вариант для кастдева

**Базовая стратегия — двойная запись:**

1. **Основной источник:** что есть штатно для канала встречи (Телемост — встроенная запись; Telegram-звонок — OBS на десктопе; очно — iPhone близко к участникам).
2. **Бэкап:** iPhone Voice Memos рядом, всегда. Если основной не получится — спасает встреча.

Для **Володи** ты записывал через Телемост + iPhone. Идеально. Я бы прогнал **Телемост-WEBM** — там чище звук собеседника. iPhone оставил как страховку, на случай если в Телемосте обрежется.

**Универсально под все случаи** — если встреч много и не хочется каждый раз думать:
- Очные → iPhone Voice Memos близко между вами
- Онлайн → встроенная запись платформы (если есть) ИЛИ OBS на десктопе ИЛИ внешний бот (см. ниже) ИЛИ iPhone через громкую связь как fallback
- Везде — iPhone Voice Memos бэкапом

## Внешние боты для онлайн-встреч

Если не хочешь возиться со скринкастом и платными тарифами Яндекса — есть боты, которые подключаются к встрече участником, пишут и транскрибируют сами. Актуальные на 2026:

| Сервис | Что делает | Поддержка платформ |
|---|---|---|
| **mymeet.ai** | Бот подключается, пишет, делает саммари и задачи | Zoom, Meet, Телемост, VK Звонки, Контур.Толк |
| **Войси (voicee.ru)** | Telegram-бот, отправляешь файл записи Телемоста — получаешь стенограмму с диаризацией | Любая запись, через ручной upload |
| **CogniCo** | Десктоп-приложение пишет звук системы, без ботов в встрече | Универсально (любая платформа) |
| **WorldSpeechAI** | Бот в встречу + интеграция с Calendar | Zoom, Meet, Телемост, Контур.Толк, VK |
| **speech2text.ru** | Бот по ссылке встречи + анализ | Zoom, Meet, Телемост |

**Для тебя сейчас выбор зависит от приоритетов:**

- **Хочется приватности и контроля** → твоя локальная схема через Whisper (то что мы и собираем). Ничего не уходит в облако, бесплатно, точность хорошая.
- **Хочется минимальной ручной работы** → mymeet.ai или voicee.ru. Сразу получаешь стенограмму с диаризацией и саммари. Платно, но экономит время.
- **Гибрид (то что я бы делал)** → локальный Whisper для большинства, бот про запас для случаев когда некогда возиться или нужна диаризация.

Для первых 5–10 кастдевов оставайся на локальном — экономия времени от ботов копится только когда поток >5 встреч в неделю.

## Правила хорошей записи

Универсальные, чтобы Whisper не срался:

1. **Близко к микрофону.** Чем ближе — тем чище. Разница между «телефон в кармане» и «телефон в 30 см от говорящего» — это разница между 70% и 95% точности.
2. **Тихая комната.** Кондиционеры, открытые окна, кафе — всё это уносит точность. Если кафе неизбежно — сядь у стены, телефон между вами.
3. **Не перебивайте.** Whisper плохо различает наложения голосов. Если перебиваете — на этих кусках будет каша.
4. **Один формат.** Не пытайся сшивать куски от разных источников в одно — Whisper подавится. Прогоняй каждый источник отдельно, потом сравни.
5. **Файл ≤500 МБ.** Большие файлы faster-whisper переварит, но если 1ГБ+ — лучше нарезать на части по часу.

## Workflow «после встречи»

```
1. Записал на двух источниках (например, Телемост + iPhone)
2. Скачал основной → положил в clients/<имя>/01_audio/
3. (Опционально) Скачал бэкап → туда же, но с суффиксом _backup
4. Запустил transcribe.py на основном
5. Проверил расшифровку — есть ли провалы в ключевых местах
6. Если есть — прогнал бэкап, сравнил, дополнил
7. Дальше — по обычному workflow (структура → пакет)
```

В большинстве случаев один источник справится. Бэкап нужен 1 раз из 10, но в этот один раз он спасает встречу.

## Конвертация WEBM в M4A (если Телемост)

Если файл с Яндекс Диска — WEBM, лучше сразу сконвертить в M4A для удобства:

```bash
ffmpeg -i recording.webm -vn -c:a aac -b:a 192k recording.m4a
```

`-vn` — отбрасывает видео. Для кастдева видео не нужно, экономит место в 5–10 раз.

После конвертации пускай `transcribe.py` на M4A.

## Что делать если встреча уже прошла, а записи нет

Случается. Если совсем ничего не записалось:

1. Сразу после встречи — продиктовать на iPhone основные пункты по памяти (что узнал, что зацепило)
2. Прогнать через Whisper свою диктовку
3. Это не полный кастдев, но скелет для разбора будет

В будущем — двойная запись с первой минуты, без исключений.
