# BOOTSTRAP — инструкция для Claude Code

> **Как использовать:** скопируй весь этот файл в чат Claude Code, в той же папке положи `custdevs.zip`. Claude Code прочитает инструкции ниже и развернёт всё сам.

---

## Контекст

Я разворачиваю систему для проведения и обработки кастдевов с потенциальными клиентами на услугу AI-автоматизации. В этой папке лежит `custdevs.zip` — готовый шаблон проекта. Тебе нужно его развернуть и подготовить рабочее окружение.

Моя машина: **Manjaro Linux**, **NVIDIA GTX 1650 SUPER (4GB VRAM)**, Python 3, Claude Code. У меня уже стоит **faster-whisper** с моделью medium (от прошлого voice-input проекта), но для кастдевов нужна **large-v3** для большей точности.

## Что нужно сделать (по шагам)

### 1. Развернуть проект ✅

Распакуй `custdevs.zip` в текущую папку. После распаковки должна быть папка `custdevs/` со структурой:

```
custdevs/
├── CLAUDE.md
├── README.md
├── scripts/
├── shared/
├── templates/
└── clients/_template/
```

Если структура не совпадает — стоп, скажи мне.

### 2. Сделать скрипты исполняемыми ✅

```bash
chmod +x custdevs/scripts/transcribe.py
chmod +x custdevs/scripts/new_client.sh
```

### 3. Проверить системные зависимости ✅

Проверь по очереди и сообщи мне статус каждого:

```bash
# faster-whisper (должен быть от voice-input)
python3 -c "from faster_whisper import WhisperModel; print('faster-whisper OK')"

# ffmpeg (нужен для конвертации видео в аудио)
ffmpeg -version | head -1

# CUDA / GPU
nvidia-smi | head -5
```

Если чего-то нет — установи:
- `ffmpeg`: `sudo pacman -S ffmpeg`
- `faster-whisper`: уже стоит, не трогай

### 4. Прогрев модели — обнаружено ограничение ⚠️

Изначально планировалось разогнать `large-v3`, но на этой машине voice-input daemon постоянно держит ~2 GB VRAM. Из 4 GB GTX 1650 SUPER остаётся ~1.4 GB — `large-v3` туда не влезает ни в `float16`, ни в `int8_float16` (обе попытки падали по `out of memory`).

**Решение:** дефолт системы — `medium`. Эта модель уже скачана и работает на этой GPU. `large-v3` остаётся опцией для критичных случаев — через ручную остановку voice-input. См. `HOWTO_LARGE_V3.md`.

Прогревать ничего не надо — `medium` уже в кэше faster-whisper.

### 5. Smoke-тест на medium

Возьми короткий аудиофайл (5–60 сек):

```bash
mkdir -p /tmp/smoketest
python3 custdevs/scripts/transcribe.py путь/к/файлу.m4a -o /tmp/smoketest/
```

Скрипт по умолчанию использует `medium`. Должны появиться три файла: `.transcript.md`, `.transcript.txt`, `.transcript.json`.

### 6. Создать тестового клиента «Владимир»

```bash
cd custdevs
./scripts/new_client.sh vladimir
```

Должна появиться папка `clients/vladimir/` со структурой шаблона.

### 7. Финальная проверка

Покажи мне дерево `custdevs/`:

```bash
find custdevs -type f | sort | head -30
```

И отчитайся:
- Что установлено / уже стояло
- Что не получилось (если что-то)
- Готова ли система к боевому прогону

## Правила работы (от меня тебе)

1. **План перед действием.** Если предстоит что-то сложнее одной команды — сначала покажи план, дождись «ок».
2. **Стоп после двух неудач.** Если что-то не работает с двух попыток — остановись, не долби третий раз тем же способом. Скажи и предложи другой путь.
3. **Не редактируй файлы шаблона** в `custdevs/` без моего разрешения. Шаблоны — основа системы.
4. **Тон — спокойный, по делу, без воды.** Не объясняй базовые вещи.

Поехали.
