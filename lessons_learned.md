# Уроки с первого кейса (Володя)

## Что работает

1. **Зеркало + связки = вау-эффект.** Клиент узнаёт свою картину переструктурированную. Связки которые он сам не делал — главный момент удивления.

2. **Метафоры клиента возвращать обязательно.** Создаёт зацепки, показывает что слушали. Володя — «парень на свидании», «цветок и пчёлы».

3. **Сегмент клиентов через его пример.** Если клиент сам привёл конкретный пример идеального клиента — собирать сегмент из него.

4. **Архетип колеса работает.** На Володе подтвердился гибрид Архетип 1+2. Больше архетипов ещё проверим.

5. **Открытая дверь без призыва.** «Если зацепит — пиши, я рядом» работает мягче чем «давай созвонимся».

## Что НЕ работает

1. **Диагностика клиента сверху.** «Ты избегал тему 40 минут» — обижает, разрушает доверие. Заменять на общий принцип или его собственные слова.

2. **Заголовок-обращение.** «Володь, посмотрел разговор внимательно» в роли h1 — некрасиво. Заголовок документа отдельно («Разбор»), обращение в первой строке текста.

3. **Призывы созвониться в пакете.** Создаёт ощущение продажи. Убрать.

4. **Цены и тарифы в пакете.** Преждевременно. Цены обсуждаются после реакции клиента, не в исходном документе.

5. **Слишком мелкий шрифт для мобильного.** 11pt на телефоне — нечитаемо. Минимум 14pt, лучше 15pt.

6. **Жёсткие page-break без проверки контента.** Создают пустые страницы и сирот. Использовать page-break-inside:avoid для блоков, разрывы между секциями только когда контент готов.

7. **wkhtmltopdf — устарел, удалён из Manjaro.** Перешли на WeasyPrint.

## Открытые вопросы для будущих кейсов

- Работает ли формат на холодных клиентах (не из мужского клуба)?
- Как меняется тон если клиент — не на «ты»?
- Все ли 7 архетипов покрыты, или появятся новые?
- Когда уместно подключать архитектурный слой (всегда / только для отдельных типов)?
