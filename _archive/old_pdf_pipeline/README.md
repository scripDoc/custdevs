# _archive/old_pdf_pipeline/ — старый PDF-разбор (выведен из эксплуатации)

**Дата архивации:** 2026-06-07
**Причина:** ROADMAP шаг 9 (расширенный). Старый pipeline кастдева заканчивался персональным
PDF-разбором клиента (meta → структурный разбор → упаковка → PDF). Этот выход больше не
используется: новый процесс строится **ТОЛЬКО из транскрипта** — транскрипт кастдева
(`02_transcript/`) уходит напрямую в лендинг-офис (Директор → стратег → … → frontend-dev).
См. `knowledge/ai-office/ROADMAP.md`, шаг 9.

## Отступление от исходной формулировки шага 9

ROADMAP шаг 9 в исходной редакции предлагал **оставить `fill_meta`** (и meta как промежуточный
артефакт). Решение при выполнении: **meta тоже упразднена, процесс transcript-only.**
Поэтому в архив ушли не только structure/package/PDF, но и весь meta-слой
(`fill_meta`, `meta_prompt.md`). Стратег офиса читает только транскрипт и сознательно
НЕ читает производные файлы (они искажают картину) — meta как вход офису не нужна.

## Что здесь лежит

| Файл | Чем был | Кто звал |
|------|---------|----------|
| `structure_prompt.md` | промпт структурного разбора расшифровки (метафоры, сегмент, архетип, принцип) → `03_structure.md` | inline («разбери»), kickoff шаг 7 |
| `package_prompt.md` | промпт финальной упаковки (5 секций: зеркало → связки → колесо → дальше → уточнить) → `04_package.md` | inline («упакуй»), kickoff шаг 8 |
| `package_template.html` | HTML-шаблон под WeasyPrint для рендера `05_final.pdf` | skill `generate_pdf` |
| `generate_pdf/` | skill: парсинг `04_package.md` → рендер `05_final.pdf` через WeasyPrint + постпроверка вёрстки | «сделай pdf», kickoff шаг 9 |
| `fill_meta/` | skill: автозаполнение `meta.md` из расшифровки через `meta_prompt.md` | «заполни мету», kickoff шаг 6 |
| `meta_prompt.md` | промпт автозаполнения meta из расшифровки (вход для `fill_meta`) | skill `fill_meta` |

## Если понадобится восстановить

Файлы перемещены через `git mv` (история сохранена). Вернуть в работу:
`git mv _archive/old_pdf_pipeline/<file> <исходный путь>` и восстановить ссылки в
`CLAUDE.md` / `kickoff` / `transcribe`. Но прежде — убедиться, что transcript-only решение
действительно откатывается, а не латается «палаткой».

## Что НЕ тронуто (живой transcript-путь)

`kickoff` (теперь кончается на транскрипте), `transcribe` (Deepgram), `enhance_audio`,
`trim_video`, `new_client` (по-прежнему скаффолдит пустой `meta.md` как слот — не ломаем),
всё в `02_transcript/`, лендинг-офис целиком (`.claude/agents/`, Директор, реестры).

## Клиентские хвосты — отдельным заходом

Старые `meta.md` / `03_structure.md` / `04_package.md` / `05_final.pdf` по конкретным
клиентам, `_old_whisper/`, `HOWTO_LARGE_V3.md` — **сюда не переносились** (другая эпоха +
клиентское локальное, не коммитится). Чистятся отдельным решением.
