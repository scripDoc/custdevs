# Лендинг для Никиты (организатор мероприятий)

## Все варианты задеплоены

| Версия | URL | Что внутри |
|---|---|---|
| Оригинал | https://kp-nikita-original.vercel.app | Исходник AI-офиса коуча (с неточностями) — baseline |
| Вариант 1 — Починка | https://kp-nikita-v1-fix.vercel.app | Чистая починка фактов, всё остальное как в оригинале |
| Вариант 2 — Природа | https://kp-nikita-v2-nature.vercel.app | + позиционирование через «продаёт уверенность» |
| Вариант 3 — Миссия | https://kp-nikita-v3-mission.vercel.app | + лейтмотив «порядок из хаоса» |

> URL выше — стабильные алиасы проектов Vercel (аккаунт `scripdoc`). При каждом
> новом деплое алиас остаётся тем же, меняется только внутренний deployment-хэш.

## Контекст

Первый клиент на продажу AI-автоматизации. Лендинг изначально собран через
AI-офис коуча, доработан под точные данные после прогона через Deepgram
с диаризацией.

## Варианты

### Оригинал
- Папка: `original/`
- Источник: AI-офис коуча
- URL: https://kp-nikita-original.vercel.app
- Статус: содержит фактические неточности (Альфа Холдинг, выдуманные имена,
  выдуманные эпизоды) — не отправлять в этом виде. Лежит для baseline-сравнения.

### Вариант 1 — Починка фактов
- Папка: `variant-1-fix/`
- URL: https://kp-nikita-v1-fix.vercel.app
- Что отличает: только починка фактических неточностей. Структура, тон,
  формулировки, дизайн — как в оригинале.
- Минимум риска. Максимум совместимости с тем что коуч уже видел.

### Вариант 2 — Природа продукта
- Папка: `variant-2-product-nature/`
- URL: https://kp-nikita-v2-nature.vercel.app
- База: Вариант 1 (факты уже починены) + акценты на природу продукта Никиты
  (продаёт уверенность, репутация как канал). Новая секция «Что ты продаёшь
  на самом деле», переписан блок «что НЕ делает агент», добавлен сценарий
  «аналитик рынка» (его собственная гипотеза со встречи).
- Срединное по риску. Сильнее по позиционированию.

### Вариант 3 — Миссия
- Папка: `variant-3-mission/`
- URL: https://kp-nikita-v3-mission.vercel.app
- База: Вариант 2 + лейтмотив «порядок из хаоса» (его собственная фраза,
  00:25:39) как сквозная тема. Заголовок и hero переработаны через миссию.
- Самый смелый. Может зайти сильно, может не зайти.

## Что общее во всех трёх

- Убран блок цены и оффера полностью (секция цен, гарантия возврата,
  поддержка/мес, плашка «50% аванс», кнопка «Скачать в PDF», пункт меню «Цена»)
- Убраны фактические неточности: Альфа Холдинг, «8 месяцев входит в курс»,
  выдуманные имена (Лёша, Лена, Маша), выдуманные клиенты (Сбер, Газпромбанк,
  Росатом), выдуманный эпизод «застройка завышено по транспорту»
- Минимально подправлен раздел про автора

## Ассеты

Картинки (`assets/`: логотип, hero-фон, favicon, og-превью) скачаны с живого
сайта коуча и лежат в каждой папке варианта. `assets/` коммитятся в git;
служебная папка `.vercel/` — нет (см. корневой `.gitignore`, правило `.vercel/`).

## Как деплоить

```bash
cd deliverables/nikita_muzh_klub/variant-1-fix
vercel --prod --yes
```

Папки уже привязаны к проектам Vercel (`.vercel/project.json`), деплой
автоматический без интерактива. Имена проектов: `kp-nikita-original`,
`kp-nikita-v1-fix`, `kp-nikita-v2-nature`, `kp-nikita-v3-mission`.
