# Деплой лендинга на Vercel

Деплоит статические HTML-страницы (лендинги) на Vercel и возвращает готовый URL.

## Триггеры
- «задеплой лендинг»
- «выложи на vercel»
- «обнови лендинг»

## Окружение

Vercel CLI установлен в `~/.npm-global/bin/`, которая **может быть не в PATH**.
Поэтому каждый вызов vercel предваряй экспортом PATH в той же команде:

```bash
export PATH="$HOME/.npm-global/bin:$PATH" && vercel --version
```

Версия проверена: Vercel CLI 54.6.1, Node 26. Авторизация — аккаунт `scripdoc`.

## Что делает

1. **Проверка готовности** (одной командой):
   ```bash
   export PATH="$HOME/.npm-global/bin:$PATH" && vercel whoami
   ```
   - Если выводит имя аккаунта — ок.
   - Если просит логин — **остановиться** и сказать пользователю выполнить `vercel login` вручную (интерактивный браузерный флоу, из Claude Code молча не запускать).

2. **Определить папку с HTML.** Если пользователь не указал путь явно — спросить одним вопросом. Папка должна содержать как минимум `index.html`.

3. **Деплой в прод** из этой папки:
   ```bash
   export PATH="$HOME/.npm-global/bin:$PATH" && cd <папка> && vercel --prod --yes
   ```
   `--yes` принимает дефолтные настройки без интерактива.

4. **Вернуть URL** — из вывода CLI (строка `Production: https://...`). Показать пользователю кликабельной ссылкой.

5. **Несколько вариантов.** Если в папке лежат подпапки `variant-1`, `variant-2`, ... (каждая со своим `index.html`) — спросить, какой деплоить, либо предложить задеплоить все по очереди (каждый получит свой URL).

## Особые случаи

- **Первый деплой папки** (нет `.vercel/`): даже с `--prod --yes` Vercel при первом запуске может спросить scope/имя проекта. Если команда зависла на вопросе — значит нужен интерактив: сказать пользователю выполнить `vercel` в этой папке руками один раз, дальше деплои автоматические. После первого раза в папке появляется `.vercel/project.json` с привязкой.
- **Статика без фреймворка:** для голого HTML Vercel разворачивает как статический сайт автоматически, конфиг не нужен.
- **Привязка к git-проекту:** если папка уже привязана к существующему Vercel-проекту (есть `.vercel/`) — использовать его конфигурацию, ничего не пересоздавать.
- **`.vercel/` в git:** не коммитить — добавить в `.gitignore`, если ещё нет (содержит ID проекта/орг).

## Правила
- Интерактивные шаги (login, первичная настройка проекта) — НЕ делать молча, отдавать пользователю.
- Ничего лишнего не ставить — деплой идёт прямым вызовом CLI.
- В отчёте — версия CLI, аккаунт, итоговый URL. Тон по делу.
