# new_client

## Перед выполнением

Прочитай `failures.md` (grep по тегам этого скилла) — если есть релевантные записи, учти их в плане. Не объясняй пользователю что делаешь grep — это фоновая проверка.

**Теги для этого скилла:** #new_client, #meta, #slug, #transliteration

## Триггеры

- «добавь нового клиента <имя>»
- «новый кастдев — <имя>»
- «создай папку для <имя>»
- «клиент <имя>, <деятельность>»

## Что делает

1. Извлекает из фразы имя клиента и (если есть) краткое описание деятельности.
2. Транслитит имя в snake_case slug:
   - Владимир → `vladimir`
   - Анна-Мария → `anna_maria`
   - Ольга Петровна → `olga_petrovna`
3. Запускает `./scripts/new_client.sh <slug>` из корня проекта `custdevs/`.
4. Сразу заполняет `clients/<slug>/meta.md`: имя, дата сегодня, описание деятельности из фразы пользователя.
5. Если в той же фразе или в недавнем сообщении пользователь упоминал особенности (характер, как общаются, контекст) — заносит в раздел meta.md.
6. Запоминает `<slug>` как «текущего клиента» для следующих команд в этой сессии (trim_video / transcribe будут по умолчанию работать с ним).
7. Отчитывается одной-двумя строками: «Создал клиента <Имя>. Папка `clients/<slug>/`. Положи исходное видео/аудио в `00_raw/`. После обрезки готовый m4a появится в `01_audio/` автоматически.»

## Параметры из контекста

| Параметр | Источник | Пример |
|---|---|---|
| `name` | имя из фразы | "Владимир" |
| `slug` | транслит + snake_case | `vladimir` |
| `description` | хвост фразы после имени, если есть | "владелец автосервиса" |
| `personality_notes` | детали характера/общения из той же или соседних фраз | "говорит медленно, любит детали" |
| `date` | сегодня в формате YYYY-MM-DD | `2026-05-01` |

## Команды

```bash
# Из корня custdevs/
./scripts/new_client.sh <slug>

# Затем редактирование clients/<slug>/meta.md через Edit/Write
```

Шаблон `meta.md` уже создаётся скриптом — заполнять, не перезаписывать.

## Обработка ошибок

- **Папка `clients/<slug>/` уже существует:** скрипт `new_client.sh` это сам ловит. Спросить пользователя — это новый клиент с похожим именем (`vladimir_2`, `vladimir_petrov`) или работаем с существующим.
- **Имя на латинице с точкой/дефисом:** заменить на `_`, привести к lower.
- **Фраза без имени** («добавь клиента»): спросить одним вопросом — «Как зовут клиента?»
- **Несколько имён в одной фразе:** сообщить, попросить уточнения какой именно.

## Отчёт пользователю

Одна-две строки результата + куда класть исходник. Без длинных списков того, какие файлы появились — это и так видно из шаблона.

Пример:
> Создал клиента Владимир. Папка `clients/vladimir/`. Положи исходное видео/аудио в `00_raw/`. После обрезки готовый m4a появится в `01_audio/` автоматически.

Если заполнял `meta.md` — упомянуть одной фразой что записал.

## После выполнения

Оценить результат по трём критериям:

1. **Провал/исправление** — что-то ломалось → запись в `failures.md`.
2. **Деградация** — отклонение от ожидаемого (скорость, качество, неожиданный fallback) → запись с тегом `#performance` или `#quality`.
3. **Неочевидное знание** — обнаружилась особенность окружения → запись с тегом `#environment`.

Если ничего из трёх — ничего не пиши.

В отчёте пользователю упоминай факт записи кратко: «Записал в failures.md (теги: #X #Y)».
